# Rambex Website

A static, GitHub-ready Rambex Off-Grid Systems website.

## Upload to GitHub

1. Create a new GitHub repository, for example `rambex-website`.
2. Upload everything inside this folder:
   - `index.html`
   - `style.css`
   - `assets/`
3. Commit the files.
4. For GitHub Pages: open **Settings → Pages**, choose **Deploy from a branch**, then select `main` and `/ (root)`.
5. Your site will then be published at the GitHub Pages address shown by GitHub.

For Cloudflare Pages, import the GitHub repository and use:
- Framework preset: None
- Build command: leave blank
- Build output directory: `/`

## Important
The contact email currently uses `info@example.com`. Replace this in `index.html` with the real Rambex email address.
